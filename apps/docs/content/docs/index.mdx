## Features

- **Use it anywhere.** Framework adapters for [AI SDK](/integrations/ai-sdk) 7, the [Pi coding agent](/integrations/pi), [Pi agent core](/integrations/pi-agent-core), and [Pi durable](/integrations/pi-durable). For any other host, `createFsTools()` gives you the tools to wrap.
- **Any filesystem.** Local files on Node or Bun, files in memory, a just-bash sandbox, or a Cloudflare Shell or Computer workspace. See [Filesystems](/filesystems).
- **Fully configurable.** Change the tool names, the parameter names, and the descriptions with a [signature](/integrations/tool-definition). Formatters, messages, limits, and hooks change the text that the model sees.
- **Bounded reads.** The [read tool](/read) stops at line, byte, and line-length limits, and at an optional token budget. It also reads images, notebooks, PDFs, and folders.
- **Read before write.** `edit` and `write` can refuse a change to a file that the model has not read, or that changed after the read. See [Read before write](/write/read-before-write).
- **Edits that find the text.** When the old text does not match exactly, `edit` tries a normalized match and tells the model. See [Matching](/write/matching).
- **Safe patches.** `apply_patch` checks the whole patch before it changes a file. See [Patches](/write/patches).
- **Permissions.** Refuse paths, protect `AGENTS.md`, `CLAUDE.md`, and `.git`, or ask the user before a change. See [Permissions](/write/permissions).
- **A bash tool with limits.** Set timeouts and output caps, save the full output to a file, and refuse or rewrite commands. See [Bash tool](/bash).
